# Rulings — 14 October 2026 (build-time, PERMISSIONS.md §15)

Made while building the desktop Operations dock and the floor-workflow (Pack · Handover · Return ·
Reset) usability passes, PR #5, branch `claude/desktop-operations-dock`. Each row is logged in three
places (B-2): here, `PROGRESS.md` under *Ruled* (entries 2026-10-14 to 2026-10-14 (g)), and a
`RULING 2026-10-14:` comment at the code site. None touches a permission, a money-visible role, an
Owner-only action, a delete path, a migration or a credential (N-1…N-8). Flip any row by replying
with its number.

These files are not in this clean repository's allowlist at the root, so this one lives in `docs/`.
