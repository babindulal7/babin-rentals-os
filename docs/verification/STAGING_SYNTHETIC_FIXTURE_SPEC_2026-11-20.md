## 1. Outbound Integration Quarantine

Before any synthetic user or record is created on staging, all external communication and payment rails must be severed:

1. **Email / SMTP:** Supabase Auth SMTP configured to discard or route to local test sink; application email sending disabled.
2. **SMS / WhatsApp:** All Twilio / WhatsApp webhook credentials omitted or pointed to dummy local endpoints. No real SMS dispatches.
3. **Payment Gateways:** No live merchant keys; sandbox/mock keys only.
4. **Booqable Cutover:** Read-only export parsing only. Outbound synchronizer hooks disabled.
5. **Turnstile / Cloudflare:** Test mode dummy keys (`1x00000000000000000000AA` for passing).
