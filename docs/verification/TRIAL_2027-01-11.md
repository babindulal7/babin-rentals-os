## Daily close

1. Staff enter each real job in both systems using their own accounts and the devices they normally use. Booqable remains the master during the trial.
2. Each evening, compare the two systems for the same reporting window. Record the window in Nepal time with the evidence links. Match booking references and events before comparing totals so a missing booking and a duplicate booking cannot cancel each other out. Count each booking once per event type and compare payment transactions by booking and amount.
3. Enter each value as **Booqable / OS**. Enter zero only after checking both sources. Record money received in NPR from the recorded transactions. Show rental payments and deposits separately in the supporting evidence. Identify refunds or reversals separately where they affect the comparison. Keep Booqable's recorded amounts and explain any rounding difference.
4. Record each discrepancy below and open a defect card the same day where the discrepancy comes from a defect. Keep supporting records in the existing restricted location. Link them without copying client contacts or payment details into this sheet.
5. Record the reviewer and set the day to **Reconciled** once the evidence accounts for every difference. Use **Open** while any difference is unexplained or evidence is missing. The trial passes after the last five days reconcile with no unexplained difference.
