## Already on `main`, unchanged here

- **R17-2 Previous period** is the same number of days immediately before (`precedingReportWindow`), offered only for a bounded period.
- **R17-3 Month labels.** "1–14 October 2026 (month to date)" only when the bucket starts on the 1st. "12–18 October 2026 (part month, to date)" for a short range; "(part month)" for a clipped month.
- **R17-4 Count-checked paging.** Exact count, advance by rows received, refuse when the count changes mid-read.
- **R17-7 Default window.** Opens on the last 90 days, so the control names the window drawn.

## Not restored: "All dates" (decision for Babin)

My earlier ruling R17-7 offered "All dates" (1st of the first issued invoice's month to today). `main` turns it off on the Revenue page: `allowAllDates={false}` on `ReportToolbar`, with the comment "Bounded readers must not offer an all-history range they cannot query." That is a deliberate choice on `main`, so this rebuild does not reverse it. To restore it, set `allowAllDates` to true and wire the earliest-issue-day reader (`getEarliestIssueDay`, already on `main`) into the window. Babin decides.
