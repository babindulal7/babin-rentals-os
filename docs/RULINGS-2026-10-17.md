# Rulings — 17 October 2026 (build-time, PERMISSIONS.md §15)

Made while porting the interactive Revenue report onto `main` after babindulal7/babin-rentals-os#12
merged its own Revenue trend and credit-note reconciliation. The work started on the closed
babindulal7/babin-rentals-os#16 (rulings R14-15…R14-21 there were never merged); this port keeps
#12's engine, reader and reconciliation and adds only what #12 lacked: a labelled value axis, a
previous-period comparison, month-to-date labels, the invoice register, a count-checked pager and the
Coordinator gate. Each row is logged in three places (B-2): here, `PROGRESS.md` under *Ruled*
(entry "Interactive Revenue report, ported onto main"), and a `RULING 2026-10-17 (R17-n)` comment at
the code site.

R17-1 narrows a report to fewer roles (B-1 stricter wins). No role is added to the money-visible set,
no capability string is renamed, no Owner-only action moves, no delete or payment-edit path is added,
no migration is written and nothing is applied to live (N-1…N-8). Flip any row by replying with its
number.
