## Backup script credential hygiene (N-8)

`scripts/backup-db.ps1` printed the full connection string, password included (`Starting native pg_dump for $DbUrl`), and both runbooks told Babin to type it on the command line, which writes it into PowerShell history.

- The script never prints the URL; it shows host, port and database only. It hands the password to pg_dump through `PGPASSWORD` for the one call and then clears it, so the password is never on a process command line. With no URL given, it prompts with hidden input.
- Dumps go to the git-ignored `backups/` folder; `production_backup_*.sql` is also git-ignored for custom paths. A run succeeds only when pg_dump's "dump complete" footer is present; otherwise the file is renamed `.incomplete`. It prints size and SHA-256 for the off-site record. The pg_dump flags are unchanged.

Revert: restore the previous script from git; the runbook lines revert with it.

## Windows display scaling: headers and tables at 125% and 150% (Task 4.2, zoom audit)

Measured in the mock build (Owner, emulated viewports, fresh load per width) at the CSS widths a 1366px and a 1920px laptop give at 125% and 150%: 1093, 911, 1536 and 1280px. Evidence: `artifacts/zoom-audit-2026-10-15/`.

Before: at 911px the Inventory and Finance titles were 0px wide, Inventory's table hid Replacement and Actions behind a 252px sideways scroll, and Operations' table hid its Action and row-link columns (92px). At 1280px with the sidebar open, which is the default on a fresh desktop load, the header is 1024px wide, narrower than a 1093px tablet's 1030px. The titles there measured Inventory 14px, Finance 15px, Operations 55px and Settings 55px. Finance's info button sat under the search box at 1280 and 1536. Every header search input was a 22px hit area inside its 44px box, and the Rentals table showed a 2px scrollbar at every width.

- **The compact header follows the header's own width** (`lib/headerRoom.ts`, `useCompactHeader`). It is compact on any tablet, and on a desktop whose header is narrower than the widest tablet header (1279 − 64 = 1216px), which in practice means the sidebar is open on a 1280–1471px window. Operations and Settings use it in place of `viewport !== 'desktop'`. Width decides (Law 14); this measures the header box, never the device. Revert: return `viewport !== 'desktop'` from `useCompactHeader`.
- **Finance and Inventory join the compact pattern.** On a compact header, Finance moves Create Invoice and Export into More and keeps Record Payment by name. Inventory moves Refresh and Export into More and drops its "N models" pill, because the list card's heading already says "N Models found". Phones are unchanged (RULINGS-2026-10-13). Revert: `compactHeader` → `phone` in both files.
- **The title keeps the header.** When the bar is full, the search gives way first (`flex: 1 20 auto` against the title zone's shrink of 1), down to a 120px box that still takes typing; only then does the title truncate. Swept across 53 static routes: no route gained an overlap, an off-screen control or header overflow. The Clients tabs trade search width for title at 911px (title 54→138px, search box 120px). Revert: `flex: '1 1 auto'` and the old 44/0 minimum in `Header.tsx`.

- **The header search box is a label** around its input, so the whole 44px box focuses the field (Law 15).
