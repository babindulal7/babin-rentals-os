# Rulings — 16 October 2026

## R-P6-STATES — a failed secondary-view read is an Error, never a figure

**Ruled 15–16 Oct 2026 (build-time authority, B-1 stricter, B-6 reversible).** A read behind a report, Settings pane or admin view throws on failure and the screen draws Error + Retry (offline-worded, retrying on reconnect) through `useLoad` + `PageBody`. It never resolves to zeros, empty rows or seed data.

| Conflict | Sources that disagreed | Decision | Why | Changed where | Revert |
|---|---|---|---|---|---|
| Queries swallowed failures into zeros/empties | Phase 6 five states + Law 16 vs the code as found | Throw; draw Error + Retry | an outage drawn as "Rs 0" or "nothing yet" is an invented figure | `pulse.ts`, `inventoryReports.ts`, `expenseReports.ts`, `activity.ts` (RULING comment at each) | restore each `catch` |
| Pulse collected-cash filter | `payment_status` enum (0001) vs `pulse.ts` | `'Received'`, not `'Completed'` | Postgres rejects `'Completed'` | `pulse.ts` | one literal |
